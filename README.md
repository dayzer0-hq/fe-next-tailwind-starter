# fe-next-tailwind-starter

Next.js (App Router) + TypeScript, styled with **Tailwind CSS**.

## Stack
- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS 3 (configured: `tailwind.config.ts`, `postcss.config.mjs`, directives in `app/globals.css`)

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Build
```bash
npm run build
```
